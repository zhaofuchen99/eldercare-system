### 1.2 并发场景：同一时段多用户预约不超卖

| # | 验收项         | 验证方式                            | 预期结果                                                | 结果 |
|---|-------------|---------------------------------|-----------------------------------------------------|----|
| 8 | 并发不超卖       | 脚本自动：建 maxCount=3 时段，4 个新用户同时预约 | 恰好 3 个成功、1 个 409「名额已满」，时段 current_count=3=max_count |    |
| 9 | 名额已满（单用户复测） | 脚本：maxCount=1 时段，同用户连约两次        | 第一次成功，第二次 409「该时段名额已满」                              |    |

> 说明：并发自动测试需要脚本从库读验证码（注册 4 个新会员）。若脚本跳过并发项，需先在 MySQL 执行一次授权（最小权限，仅 SELECT 验证码表）：
> ```sql
> CREATE USER IF NOT EXISTS 'smoke'@'172.22.%' IDENTIFIED BY 'smoke_pass';
> GRANT SELECT ON eldercare.sms_code TO 'smoke'@'172.22.%';
> ```
> 脚本默认 `DB_HOST` 取 WSL 网关 IP（Windows 主机），可用环境变量覆盖。不授权则并发/注册自动 SKIP，手工替代方案——浏览器开 4 个无痕窗口用 4 个账号同时点击预约同一时段，观察是否只有 max_count 个成功。
