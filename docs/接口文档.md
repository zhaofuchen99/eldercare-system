## 0. 通用约定

### 0.1 认证方式

除登录/注册/验证码外，所有接口需在请求头携带：

```
Authorization: Bearer <accessToken>
```

Access Token 有效期 2 小时，过期后可用 Refresh Token 刷新（`/api/auth/refresh`）。

### 0.2 统一响应结构 `Result<T>`

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "traceId": null
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 状态码，与 HTTP 状态对齐 |
| message | string | 提示信息 |
| data | object | 业务数据 |
| traceId | string | 错误响应时的追踪 ID |

### 0.3 状态码

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 请求参数错误（缺失/格式错误/越界） |
| 401 | 未登录或 Token 无效/过期 |
| 403 | 无权限（角色不足、资源非本人） |
| 404 | 资源不存在 |
| 409 | 业务冲突（名额已满、积分不足、重复操作） |
| 429 | 请求过于频繁（限流） |
| 500 | 系统内部错误 |

### 0.4 分页约定

分页接口统一使用 `page`（页码，默认 1）、`size`（每页条数，默认 10）查询参数，响应统一为 `PageVO<T>`：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "pageNum": 1,
    "pageSize": 10,
    "total": 35,
    "pages": 4,
    "list": []
  }
}
```

### 0.5 枚举编码约定

数据库中的枚举均存**英文编码**（如 `MEMBER/ADMIN`、`PUBLISHED/DRAFT`、`USER/ASSISTANT`），中文含义由前端映射展示。

## 1. 认证授权模块

### 1.1 发送短信验证码

- **URL**：`POST /api/sms/code`
- **认证**：无
- **请求体**：

```json
{ "phone": "13800138000" }
```

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| phone | string | 是 | 手机号，格式 `^1[3-9]\d{9}$` |

- **说明**：当前为本地模拟发送，验证码 6 位、5 分钟有效；限流 3 次/分钟、10 次/天，超出返回 429。
- **响应**：`Result<Void>`，message 为「验证码已发送」。

### 1.2 注册

- **URL**：`POST /api/auth/register`
- **认证**：无
- **请求体**：

```json
{ "phone": "13800138000", "code": "123456", "password": "Test@1234" }
```

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| phone | string | 是 | 手机号格式 |
| code | string | 是 | 短信验证码 |
| password | string | 是 | 长度 ≥ 8，必须同时包含字母和数字 |

- **说明**：校验手机号未注册、验证码正确后创建会员（等级 NORMAL、启用），赠送注册积分（sys_config `register_bonus_points`，默认 100），签发双 Token。
- **响应**：`Result<LoginVO>`（见 1.3）。
- **错误**：409 手机号已注册；400 验证码错误/过期。

### 1.3 登录

- **URL**：`POST /api/auth/login`
- **认证**：无
- **请求体**：

```json
{ "phone": "13800138000", "password": "Test@1234" }
```

- **响应** `Result<LoginVO>`：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiJ9...",
    "tokenType": "Bearer",
    "expiresIn": 7200,
    "userInfo": {
      "id": 2,
      "phone": "13800138000",
      "realName": "测试用户",
      "avatar": null,
      "memberLevel": "NORMAL",
      "points": 1000,
      "role": "MEMBER"
    }
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| accessToken | string | 访问令牌，2 小时 |
| refreshToken | string | 刷新令牌，7 天 |
| tokenType | string | 固定 `Bearer` |
| expiresIn | long | Access Token 剩余秒数 |
| userInfo | object | 用户信息（不含密码） |

- **错误**：400 手机号或密码错误；400 账号已被禁用。

### 1.4 刷新 Token

- **URL**：`POST /api/auth/refresh`
- **认证**：无
- **请求体**：`{ "refreshToken": "..." }`
- **响应** `Result<TokenVO>`：

```json
{ "accessToken": "...", "refreshToken": "...", "tokenType": "Bearer", "expiresIn": 7200 }
```

- **说明**：Refresh Token 有效且用户未被强制下线时返回新 Access Token；原 Refresh Token 继续有效（沿用直至过期）。
- **错误**：401 Refresh Token 无效或已过期 / 用户被强制下线 / 账号禁用。

### 1.5 登出

- **URL**：`POST /api/auth/logout`
- **认证**：Bearer（非强制，携带则黑名单）
- **请求头**：`Authorization: Bearer <accessToken>`（可选）
- **请求体**：`{ "refreshToken": "..." }`
- **说明**：Access Token 加入 Redis 黑名单（TTL 与剩余有效期一致），Refresh Token 从数据库物理删除。
- **响应**：`Result<Void>`。

### 1.6 密码找回

- **URL**：`POST /api/auth/forgot-password`
- **认证**：无
- **请求体**：`{ "phone": "...", "code": "...", "newPassword": "Test@1234" }`（newPassword 规则同注册密码）
- **说明**：验证短信验证码后重置密码，并强制该用户所有设备下线。
- **响应**：`Result<Void>`。

### 1.7 修改密码

- **URL**：`POST /api/auth/change-password`
- **认证**：Bearer（必填）
- **请求体**：`{ "oldPassword": "...", "newPassword": "Test@1234" }`
- **说明**：校验原密码后重置，并强制该用户所有设备下线。
- **响应**：`Result<Void>`；400 原密码错误。

## 2. 健康记录模块

> 指标阈值提醒（文档 5.2）：收缩压 90-139 / 舒张压 60-89 / 空腹血糖 3.9-6.1 / 心率 60-100 / BMI 18.5-23.9。录入后超标项生成健康指导并推站内消息，同一指标当日去重。AI 个性化建议当前为模板（接入 5.4 后替换）。

### 2.1 录入健康数据

- **URL**：`POST /api/member/health`
- **认证**：Bearer
- **请求体**：

```json
{ "systolic": 130, "diastolic": 85, "bloodSugar": 5.2, "heartRate": 72, "weight": 62.5, "memo": "晨起测量" }
```

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| systolic | int | 否 | 30-250 |
| diastolic | int | 否 | 30-150 |
| bloodSugar | decimal | 否 | 1.0-30.0 |
| heartRate | int | 否 | 20-250 |
| weight | decimal | 否 | 10.0-300.0 |
| memo | string | 否 | ≤500 字 |

- **说明**：至少填一项；有身高档案时按 `weight / (身高m)²` 自动算 BMI；超标触发健康提醒。
- **响应**：`Result<Long>`（健康记录 ID）。

### 2.2 历史记录查询（会员）

- **URL**：`GET /api/member/health/history?page=1&size=10`
- **认证**：Bearer（查询本人）
- **响应** `Result<PageVO<HealthRecordVO>>`：

```json
{
  "code": 200,
  "data": {
    "pageNum": 1, "pageSize": 10, "total": 1, "pages": 1,
    "list": [{
      "id": 1, "systolic": 130, "diastolic": 85, "bloodSugar": 5.2,
      "heartRate": 72, "weight": 62.5, "bmi": 23.4, "memo": "晨起测量",
      "recordedTime": "2026-08-17T10:00:00"
    }]
  }
}
```

- 排序：记录时间倒序。

### 2.3 健康趋势（会员）

- **URL**：`GET /api/member/health/trend`
- **认证**：Bearer
- **响应** `Result<HealthTrendVO>`（近 6 个月，按月聚合，key 为指标编码）：

```json
{
  "code": 200,
  "data": {
    "data": {
      "SYSTOLIC": [ { "month": "2026-03", "avg": 128.0, "max": 140, "min": 120 } ],
      "BLOOD_SUGAR": [ { "month": "2026-03", "avg": 5.4, "max": 6.0, "min": 5.0 } ]
    }
  }
}
```

- 指标编码：`SYSTOLIC`/`DIASTOLIC`/`BLOOD_SUGAR`/`HEART_RATE`/`BMI`（只返回有数据的指标）。

### 2.4 健康档案分页查询（管理端）

- **URL**：`GET /api/admin/health-record?userId=2&page=1&size=10`
- **认证**：Bearer（需 ADMIN）
- **响应**：同 2.2 `Result<PageVO<HealthRecordVO>>`。

### 2.5 健康趋势查询（管理端）

- **URL**：`GET /api/admin/health-record/trend?userId=2&indicator=SYSTOLIC`
- **认证**：Bearer（需 ADMIN）
- **参数**：`userId` 必填；`indicator` 可选（不填返回全部指标）。
- **响应**：同 2.3 `Result<HealthTrendVO>`。

## 3. 健康评测模块

### 3.1 已发布问卷列表（会员）

- **URL**：`GET /api/member/assessment/questionnaires`
- **认证**：Bearer
- **响应** `Result<List<MemberQuestionnaireVO>>`：

```json
{ "code": 200, "data": [ { "id": 1, "title": "基础健康状况调查问卷", "description": "..." } ] }
```

### 3.2 问卷详情（会员，答题用）

- **URL**：`GET /api/member/assessment/questionnaire/{id}`
- **认证**：Bearer
- **响应** `Result<MemberQuestionnaireDetailVO>`：

```json
{
  "code": 200,
  "data": {
    "id": 1, "title": "基础健康状况调查问卷", "description": "...",
    "questions": [
      { "id": 1, "content": "您的年龄是？", "type": "SINGLE", "options": ["18-30岁", "31-45岁", "46-60岁", "60岁以上"] },
      { "id": 2, "content": "请简要描述您目前的健康状况", "type": "TEXT", "options": [] }
    ]
  }
}
```

- 说明：仅已发布问卷可答（否则 403）；选项仅返回文案（不暴露分值/语义，避免影响作答）。
- 题型编码：`SINGLE` 单选 / `MULTIPLE` 多选 / `TEXT` 文本。

### 3.3 提交评测（会员）

- **URL**：`POST /api/member/assessment/submit`
- **认证**：Bearer
- **请求体**（value：单选为选项下标数字，多选为下标数组，文本为字符串）：

```json
{
  "questionnaireId": 1,
  "items": [
    { "qid": 1, "value": 3 },
    { "qid": 2, "value": 0 },
    { "qid": 3, "value": [1, 2] },
    { "qid": 4, "value": "睡眠一般，半夜易醒" }
  ]
}
```

- **说明**：需完成全部题目；服务端计算规则分（百分制）、AI 评分（当前 Mock：`ai_score = 规则分`）、按 `grade_rules` 判定等级；完成赠送 20 积分（sys_config `health_assessment_bonus_points`）。
- **响应**：`Result<Long>`（评测结果 ID）。
- **错误**：404 问卷不存在；409 问卷未发布；400 未完成题目。

### 3.4 评测历史（会员）

- **URL**：`GET /api/member/assessment/history?page=1&size=10`
- **认证**：Bearer
- **响应** `Result<PageVO<AssessmentResultListVO>>`，列表项字段：`id`、`questionnaireId`、`questionnaireTitle`、`ruleScore`、`aiScore`、`createTime`。

### 3.5 评测报告详情（会员）

- **URL**：`GET /api/member/assessment/result/{id}`
- **认证**：Bearer（仅本人）
- **响应** `Result<AssessmentResultDetailVO>`：

```json
{
  "code": 200,
  "data": {
    "id": 1, "questionnaireId": 1, "questionnaireTitle": "基础健康状况调查问卷",
    "ruleScore": 80, "aiScore": 80,
    "aiSuggestion": "根据您的健康评测结果...",
    "grade": "良好",
    "createTime": "2026-08-17T11:00:00",
    "items": [
      { "qid": 2, "content": "您的睡眠质量如何？", "type": "SINGLE",
        "answerText": "很好，每天睡 7-8 小时", "meaning": "睡眠充足，质量良好", "score": 10 }
    ]
  }
}
```

- 说明：`grade` 按 `grade_rules` 匹配 `aiScore`；文本题无 `meaning`/`score`。

### 3.6 创建问卷（管理端）

- **URL**：`POST /api/admin/assessment/questionnaire`
- **认证**：Bearer（需 ADMIN）
- **请求体**：

```json
{
  "title": "睡眠质量调查",
  "description": "了解睡眠状况",
  "totalScore": 20,
  "passScore": 60,
  "gradeRules": [
    { "min": 90, "label": "优秀", "description": "..." },
    { "min": 60, "label": "及格", "description": "..." }
  ]
}
```

- **说明**：创建后状态为 `DRAFT`；`totalScore` 应等于所有计分题 `max_score` 之和（由管理员维护）。
- **响应**：`Result<Long>`（问卷 ID）。

### 3.7 编辑问卷（管理端）

- **URL**：`PUT /api/admin/assessment/questionnaire/{id}`
- **认证**：Bearer（需 ADMIN）
- **请求体**：同 3.6。
- **响应**：`Result<Void>`。

### 3.8 删除问卷（管理端）

- **URL**：`DELETE /api/admin/assessment/questionnaire/{id}`
- **认证**：Bearer（需 ADMIN）
- **说明**：问卷连同其下题目一并逻辑删除。
- **响应**：`Result<Void>`。

### 3.9 发布/下架（管理端）

- **URL**：`PUT /api/admin/assessment/questionnaire/{id}/status?status=PUBLISHED`
- **认证**：Bearer（需 ADMIN）
- **参数**：`status` = `DRAFT` / `PUBLISHED`。
- **响应**：`Result<Void>`；400 状态不合法。

### 3.10 问卷列表（管理端）

- **URL**：`GET /api/admin/assessment/questionnaires?page=1&size=10`
- **认证**：Bearer（需 ADMIN）
- **响应** `Result<PageVO<QuestionnaireAdminVO>>`，列表项字段：`id`、`title`、`description`、`status`、`totalScore`、`passScore`、`gradeRules`（数组，`{min,label,description}`）、`createTime`。

### 3.11 题目列表（管理端）

- **URL**：`GET /api/admin/assessment/questionnaire/{id}/questions`
- **认证**：Bearer（需 ADMIN）
- **响应** `Result<List<QuestionAdminVO>>`，字段：`id`、`content`、`type`、`scoreMode`、`options`（数组，`{text,meaning,score}`）、`maxScore`、`sortOrder`。

### 3.12 批量保存题目（管理端，覆盖式）

- **URL**：`POST /api/admin/assessment/questionnaire/{id}/questions`
- **认证**：Bearer（需 ADMIN）
- **请求体**（`id` 可为 null）：

```json
[
  {
    "id": null,
    "content": "您是否吸烟？",
    "type": "SINGLE",
    "scoreMode": "NON_SCORED",
    "options": [ { "text": "否", "meaning": "不吸烟，风险低" }, { "text": "是", "meaning": "吸烟，风险较高" } ],
    "maxScore": 0,
    "sortOrder": 1
  },
  {
    "id": null,
    "content": "请描述您近期的运动情况",
    "type": "TEXT",
    "scoreMode": "NON_SCORED",
    "options": [],
    "maxScore": 10,
    "sortOrder": 2
  }
]
```

- 说明：先逻辑删除该问卷下全部旧题，再按数组顺序重建。
- 计分模式：`SCORED`（选项须带 `score`）/ `NON_SCORED`（仅 `text`+`meaning`）；文本题不能配选项。

### 3.13 编辑单题（管理端）

- **URL**：`PUT /api/admin/assessment/question/{id}`
- **认证**：Bearer（需 ADMIN）
- **请求体**：同 3.12 中单题对象。
- **响应**：`Result<Void>`。

### 3.14 删除单题（管理端）

- **URL**：`DELETE /api/admin/assessment/question/{id}`
- **认证**：Bearer（需 ADMIN）
- **响应**：`Result<Void>`。

## 4. AI 对话模块

> 说明：对话上下文取最近 10 轮；首条消息后 AI 自动生成会话标题（失败兜底取首条消息前 20 字）；AI 接口错误时用户消息正常保存、助手消息打 `FAILED` 标记。需要 `DEEPSEEK_API_KEY` 环境变量才能真实调用（未配时返回失败标记）。

### 4.1 创建会话

- **URL**：`POST /api/member/chat/session`
- **认证**：Bearer
- **说明**：会话名称置空，发送首条消息后自动生成。
- **响应**：`Result<Long>`（会话 ID）。

### 4.2 会话列表

- **URL**：`GET /api/member/chat/sessions?page=1&size=10`
- **认证**：Bearer
- **响应** `Result<PageVO<ChatSessionVO>>`，列表项字段：`id`、`sessionName`、`createTime`、`updateTime`（按 update_time 倒序，最近对话置顶）。

### 4.3 删除会话

- **URL**：`DELETE /api/member/chat/session/{id}`
- **认证**：Bearer
- **说明**：会话与全部消息逻辑删除。
- **响应**：`Result<Void>`。

### 4.4 消息历史

- **URL**：`GET /api/member/chat/session/{id}/messages?page=1&size=10`
- **认证**：Bearer
- **响应** `Result<PageVO<ChatMessageVO>>`，列表项字段：`id`、`role`（`USER`/`ASSISTANT`）、`message`、`status`（`SUCCESS`/`FAILED`）、`createTime`（倒序）。

### 4.5 发送消息（非流式）

- **URL**：`POST /api/member/chat/message`
- **认证**：Bearer
- **请求体**：

```json
{ "sessionId": 1, "content": "高血压平时要注意什么？" }
```

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| sessionId | long | 是 | 本人会话 |
| content | string | 是 | ≤2000 字 |

- **响应**：`Result<String>`（AI 回复全文）。
- **错误**：404 会话不存在；403 无权访问；500 AI 服务暂不可用。

### 4.6 流式对话（SSE）

- **URL**：`POST /api/member/chat/message/stream`
- **认证**：Bearer（SSE 请求同样携带 `Authorization` 头）
- **请求体**：同 4.5。
- **响应**：`text/event-stream`，逐字推送 AI 回复（打字机效果），结束时客户端可请求 4.4 拉取完整消息。
- **说明**：SSE 超时 60s；客户端断开/超时/错误均保证已生成内容已落库（部分内容按成功消息保存，无内容则助手消息打 FAILED）。
